# 图片投放目录

完整的统一视觉设定、人物档案与 8 张逐图提示词见 [`IMAGE_PROMPTS.md`](IMAGE_PROMPTS.md)。

把图片放进本目录，并使用下表中的文件名。刷新网页后，对应的“图片预留”区域会自动显示图片；不需要修改 JavaScript 或 HTML。

支持扩展名：`.jpg`、`.jpeg`、`.png`、`.webp`、`.avif`。同一名称存在多个格式时，按上述顺序使用第一个可读取文件。

图片显示比例为 `16:9`，超出部分会居中裁切。建议使用至少 `1280 x 720` 的横图。
